# Licensing scope / 许可范围

ZooWork's original component code and CSS are licensed under Apache-2.0; see `LICENSE`. The `license` field in the npm manifests describes this code. Existing third-party portions retain their original licenses and copyright notices, including adapted shadcn/ui code and Heroicons paths. See `THIRD_PARTY_NOTICES.md` and `third-party/SOURCE_ATTRIBUTION.md`.

Fonts retain their own OFL terms, copyright notices and Reserved Font Names. `third-party/inventory.json` maps all 210 font binaries to their source and SHA-256. GFS Didot's original embedded metadata, including the historical `1.1-review1` wording, is preserved alongside the supplied OFL-1.1 text for review; it has not been rewritten.

Brand names, logos, certification marks, avatars, illustrations, videos and other non-code visual assets are not covered by the project's Apache-2.0 code grant unless separately stated. Third-party marks remain the property of their respective owners. Inclusion in an internal package is not a grant of trademark rights or a representation of certification. Public redistribution scope for these assets remains to be confirmed.

The dependency inventory describes the audited lockfile, not every version allowed by dependency ranges. npm dependencies remain external imports and are installed separately; their own licenses also travel with their packages. Before upgrading dependencies, refresh the evidence and regenerate the notices. Before publishing a bundled application or a design file, carry forward the notices applicable to the content actually included.

This change prepares license attribution in the repository and installable tarballs. It does not change npm access from restricted, publish a package, approve public asset scope, or publish the Figma library.
